## 변경 요약
사용자 피드백: "업무담당자로 로그인 했을때 판단경로가 너무 아래에 있어." `/requests/{id}`
상세 화면에서 "판단 경로"(및 바로 아래의 "다음 판단" 액션)가 화면 첫 스크롤 없이는
안 보일 만큼 아래에 있던 문제를 레이아웃 재배치로 해결. 겸사겸사 "잘못 배정된 청구를
다른 사람에게 넘기는 기능이 있는지" 확인 요청도 같이 답변(결론: 이미 있음, 아래 참고).

## 변경 내용
- `app/templates/request_detail.html`: "접수 정보"/"AI 식별 결과"/"반복 청구 판정" 3개
  참고용 카드(`metric-split`)를 화면 맨 위(청구 원문보다도 앞)에서 판단 경로·처리
  이력 섹션 **아래**의 새 "참고 정보" 패널로 이동. 새 페이지 순서: 청구 원문 →
  판단 경로/처리 이력(+담당자 배정·재배정·거절 등 액션 카드) → 참고 정보.
  Jinja 조건문(`dispatcher_limited_view` 등)은 전부 그대로 유지, 블록 위치만 이동.
- 이렇게 바꾼 이유: 참고 카드 3개가 실제 콘텐츠 양과 무관하게 CSS 그리드에서 서로
  높이를 맞춰 늘어나(`align-items: stretch` 기본값) 매번 ~300px를 차지했음 — 청구
  원문이 한 줄짜리로 아주 짧아도 "판단 경로"가 뷰포트(1440×900) 기준 907px 지점까지
  밀려나 있었다. 참고 카드는 매 판단 단계마다 봐야 하는 정보가 아니라(한 청구당 여러
  번 단계를 밟을 때마다 화면이 다시 로드되는데, 매번 이 카드들을 지나쳐야 했음) 아래로
  내려도 손해가 없고, 반대로 판단 경로·액션 카드는 매번 즉시 필요한 정보라 위로 올렸다.
  같은 이유로 총괄관리자·배정담당자 화면도 동일하게 개선됨(역할별 분기 아님, 공용
  템플릿이라 전체 개선).
- 원문 표시 영역에 "청구 원문" 소제목(`.dispatch-label`)을 추가 — 기존엔 참고 카드들
  바로 아래에 있어 굳이 이름표가 없어도 맥락상 명확했지만, 이제 헤더 바로 아래로
  옮기면서 라벨이 있는 게 더 명확함.

## 원인
사용자 직접 피드백. 스크린샷 대신 Playwright로 뷰포트 내 "판단 경로" 위치를 실측
(907px → 537px, -370px)해서 실제 개선 폭을 확인.

## 검증
- 확인 방법: `python -m compileall app` 통과, `pytest` 41개 전부 통과(DOM 위치를
  검사하는 테스트는 없어 영향 없음, 텍스트 존재 여부만 검사하는 기존 테스트는 블록
  이동과 무관하게 그대로 통과).
- 개발 서버 재기동 후 Playwright로 실측: staff10으로 로그인해 배정된 청구(#10, 원문
  1줄) 상세 화면 진입 → "판단 경로" 헤딩 y좌표 907px → **537px**로 개선, 1440×900
  뷰포트에서 "예(Y)/아니오(N)" 버튼까지 스크롤 없이 바로 보임(전후 스크린샷 비교로
  확인).
- 총괄관리자·배정담당자 계정으로 같은 청구 상세 화면을 각각 스크린샷 — 참고 정보
  섹션이 아래로 이동했을 뿐 카드 내용·조건부 렌더링(배정담당자는 반복청구판정 카드
  안 보임 등, FOIA-0019 규칙)은 전부 그대로 유지됨을 확인. 모바일 뷰포트(390×844)에서
  가로 스크롤 발생 없음도 확인.
- **"잘못 배정된 청구 재배정" 기능 확인 요청에 대한 답**: 이미 있음(FOIA-0009).
  업무담당자 화면의 "잘못 배정되었나요?" 카드에서 넘길 담당자를 1~3명 지정해 재배정
  요청할 수 있고(단순 반려는 불가, 반드시 대상자 지정), 이 화면 스크린샷에서도 그
  카드가 정상적으로 보이는 것을 재확인.

## 리스크
- 영향 범위: `request_detail.html` 레이아웃만 변경, 백엔드 로직·데이터·권한 판단은
  전혀 건드리지 않음(순수 HTML 블록 재배치).
- 주의사항: 참고 정보(접수정보/AI식별결과/반복청구판정)가 이제 페이지 하단에 있다는 걸
  향후 이 화면에 새 참고용 카드를 추가하는 사람이 인지해야 함 — 판단/액션과 무관한
  정보는 "참고 정보" 패널에, 매 단계 즉시 필요한 정보/액션은 판단 경로 옆 패널에 넣을 것.
